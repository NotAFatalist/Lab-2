## Что сделано

### books.csv / books-en.csv — `main.py`

| № | Задание | Реализация |
|---|---------|------------|
| 1 | Количество записей с названием длиннее 30 символов | `count_long_titles()` |
| 2 | Поиск книги по автору с ограничением выдачи по варианту | `search_by_author()`: для `books.csv` — год поступления ≥ 2018, для `books-en.csv` — год издания ≥ 2000 |
| 3 | 20 библиографических ссылок `<автор>. <название> - <год>` | `make_bibliography()` + `save_bibliography()` → `bibliography.txt` (нумерованный список) |
| 4 | Допзадание: перечень без повторений | `unique_values()`: для `books.csv` — теги жанров, для `books-en.csv` — издательства |
| 5 | Допзадание: 20 самых популярных книг | `top_books()`: по «Кол-во выдач» / по `Downloads` |

### currency.xml — `main.py`

`parse_currencies()` разбирает XML через `xml.dom.minidom` (кодировка `windows-1251`
берётся из заголовка файла) и формирует **словарь «Name - CharCode»** — согласно варианту 10.
Результат печатается и сохраняется в `currencies.json`.

## Запуск

```bash
python main.py                     # все задания по books.csv + currency.xml
python main.py --author Пушкин     # только поиск по автору (без вопросов в консоли)
python main.py --en                # те же задания по books-en.csv
python main.py --en --author Rowling
python main.py --xml               # только разбор currency.xml
```

Без ключа `--author` поиск работает в диалоговом режиме: вводится фамилия или её часть,
`0` или пустая строка — выход. Найденные записи дополнительно сохраняются в `result.txt`.

> Файлы `books.csv` и `books-en.csv` сохранены в кодировке **windows-1251**, поэтому
> читаются с `encoding="cp1251"`. Разделитель полей — `;`.
